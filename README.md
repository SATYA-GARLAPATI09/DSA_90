# ⚔️ 90-Day DSA War Room

A high-focus, zero-excuses productivity tracker designed for the **90-Day DSA Mastery Challenge** (150 LeetCode problems across 18 patterns).

## 🚀 Live Demo & Deployment
This project is self-contained with **zero dependencies**. You can deploy it instantly on **Vercel**, **GitHub Pages**, or **Netlify**.

### 🌟 Features
- **150-Problem Roadmap**: Embedded complete problem list from Easy to Hard.
- **Customizable Pomodoro Timer**: Switch between `25/5`, `50/10`, `45/15`, or custom durations.
- **Interactive Algorithm Visualizers**: Covers all 18 DSA patterns with step-by-step state animations.
- **Strict Discipline Gating**: Enforces problem review, approach notes ($\ge 15$ chars), and verified GitHub commit logging.
- **100% Private Client Storage**: Every user gets their own isolated local database without needing sign-ups or server costs.
- **Multiple Focus Color Palettes**: Obsidian Cyber, Forest Focus, Tokyo Night, and Clean Light.
- **Data Backup & Restore**: One-click JSON backup & restore.

## 📦 Deployment to Vercel
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"** → Import this repository.
3. Click **"Deploy"** (no build settings required).
